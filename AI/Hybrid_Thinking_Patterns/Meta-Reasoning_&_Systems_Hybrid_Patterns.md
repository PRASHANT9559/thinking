## Section 8: Meta-Reasoning & Systems Hybrid Patterns (High-level Cognition)

| Hybrid Thinking Pattern | Combined Patterns | Where It Is Used | Description |
|-------------------------|-------------------|------------------|-------------|
| **Systems Thinking with Simulation (STS)** | Systems Thinking + Mental Simulation | Complex policy analysis, sustainability modeling | Simulates system dynamics while reasoning about emergent properties and feedback loops |
| **Second-Order Planning (SOP)** | Second-Order Thinking + Planning + Reflection | Strategic AI, long-term consequences | Plans while considering the consequences of the plan itself, with reflection on meta-level effects |
| **Probabilistic Tree of Thought (PTT)** | Probabilistic Thinking + Tree-of-Thought | Decision under uncertainty, Bayesian planning | Tree branches have probability distributions, with reasoning about expected values and risks |
| **First-Principles RAG (FP-RAG)** | First Principles Thinking + Retrieval Augmented Generation | Innovation research, scientific discovery | Breaks problems to fundamentals while retrieving foundational scientific principles |
| **Lateral Tree Search (LTS)** | Lateral Thinking + Tree-of-Thought | Creative problem solving, design thinking | Explores unconventional solution branches, using lateral thinking to escape local optima |
| **Feedback Loop Planning (FLP)** | Feedback Loop Analysis + Dynamic Planning | Control systems, economic policy | Plans explicitly account for feedback effects, with dynamic adjustment as loops activate |
| **Emergence-Aware Multi-Agent (EAMA)** | Emergence Recognition + Multi-Agent Orchestration | Complex adaptive systems, game theory | Agents recognize and leverage emergent collective behaviors that arise from local interactions |
| **Trade-off Tree Analysis (TTA)** | Trade-off Analysis + Tree-of-Thought | Multi-objective optimization, Pareto analysis | Tree branches represent different trade-off configurations, systematically exploring Pareto frontiers |
| **Scenario-Based Reflection (SBR)** | Scenario Planning + Reflection + Counterfactual | Strategic foresight, risk management | Reflects on performance across multiple future scenarios to identify robust strategies |
| **Root Cause CoT (RCCoT)** | Root Cause Analysis + Chain-of-Thought | Troubleshooting, quality assurance | Step-by-step reasoning traces problems to root causes using systematic analysis techniques |
