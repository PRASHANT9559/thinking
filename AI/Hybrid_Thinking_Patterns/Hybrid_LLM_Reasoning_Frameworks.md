## Section 1: Hybrid LLM Reasoning Frameworks (Knowledge + Reasoning)

| Hybrid Thinking Pattern | Combined Patterns | Where It Is Used | Description |
|-------------------------|-------------------|------------------|-------------|
| **Retrieval-Augmented Chain-of-Thought (RACoT)** | Chain-of-Thought + Retrieval Augmented Generation | Research assistants, legal analysis, medical diagnosis | Generates step-by-step reasoning where each step is grounded by retrieving external knowledge, ensuring factual accuracy throughout the reasoning chain |
| **Verified Chain-of-Thought (VCoT)** | Chain-of-Thought + Reflection | Critical analysis systems, fact-checking AI | Generates reasoning steps, then reflects on and verifies each step's validity before proceeding to the next conclusion |
| **Tree-of-Knowledge (ToK)** | Tree-of-Thought + Retrieval Augmented Generation | Exploratory research, hypothesis generation | Explores multiple reasoning branches while grounding each node in retrieved facts, pruning branches with weak evidence |
| **Reflective Tree Search (RTS)** | Tree-of-Thought + Reflection | Strategic planning, game playing | Expands reasoning trees while continuously reflecting on branch quality, self-correcting paths that show promise but contain flaws |
| **Program-of-Thought with Verification (PoT-V)** | Program-of-Thought + Reflection | Code generation, mathematical proof systems | Generates executable programs to solve problems, then reflects on execution results to debug and optimize the code |
| **Graph-of-Knowledge Reasoning (GoKR)** | Graph-of-Thought + Retrieval Augmented Generation | Enterprise knowledge systems, scientific discovery | Constructs reasoning graphs where nodes are linked to retrieved documents, enabling traceable multi-hop inference |
| **Self-Correcting Analogical Reasoning (SCAR)** | Analogical Reasoning + Reflection | Cross-domain innovation, creative problem solving | Applies analogies from source domains to target problems, then reflects on analogy validity and adjusts mapping accordingly |
| **Retrieval-Augmented Step-Back (RASB)** | Step-Back Prompting + Retrieval Augmented Generation | Scientific Q&A, physics tutoring | Retrieves general principles first, then applies them to specific problems while grounding each application in relevant facts |
| **Consistent Multi-Chain Reasoning (CMCR)** | Self-Consistency with CoT + Retrieval Augmented Generation | High-stakes decision support, medical diagnosis | Generates multiple knowledge-grounded reasoning chains and selects answers with both high consistency and evidence support |
| **Hierarchical Retrieval CoT (HRCoT)** | Chain-of-Thought + Hierarchical Retrieval | Legal reasoning, policy analysis | Reasons through complex problems by retrieving information at different abstraction levels (principles → cases → details) |
| **Counterfactual RAG (CRAG)** | Counterfactual Reasoning + Retrieval Augmented Generation | Causal inference, policy simulation | Retrieves facts to construct counterfactual scenarios, then reasons about alternative outcomes based on grounded evidence |
| **Verified Program Execution (VPE)** | Program-of-Thought + Self-Consistency | Financial modeling, engineering calculations | Generates multiple program solutions, executes all, and uses statistical consistency to verify computational correctness |
| **Structured Reflection CoT (SRCoT)** | Structured CoT + Reflection | Formal verification, theorem proving | Follows strict logical formats in reasoning, with reflection steps that check adherence to formal rules and axioms |
| **Abductive Retrieval Reasoning (ARR)** | Abductive Reasoning + Retrieval Augmented Generation | Diagnostic systems, root cause analysis | Retrieves potential explanations from knowledge bases, then uses abduction to select the most plausible hypothesis |
| **Temporal Knowledge Reasoning (TKR)** | Temporal Reasoning + Retrieval Augmented Generation | Historical analysis, forecasting systems | Retrieves time-stamped information to construct accurate temporal sequences and reason about cause-effect across time |
