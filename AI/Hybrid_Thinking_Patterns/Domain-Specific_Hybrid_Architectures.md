## Section 7: Domain-Specific Hybrid Architectures (Specialized Applications)

| Hybrid Thinking Pattern | Combined Patterns | Where It Is Used | Description |
|-------------------------|-------------------|------------------|-------------|
| **Legal CoT with Precedent (LCoTP)** | Legal Reasoning + Chain-of-Thought + Retrieval | Legal research, case law analysis | Step-by-step reasoning retrieves and applies legal precedents at each inference step |
| **Diagnostic Reflection Tree (DRT)** | Medical Diagnostic Reasoning + Tree-of-Thought + Reflection | Clinical decision support, differential diagnosis | Explores diagnostic hypotheses as a tree, reflecting on evidence fit for each branch |
| **Scientific Method CoT (SMCoT)** | Scientific Reasoning + Chain-of-Thought + Experiment Design | Research automation, hypothesis testing | Reasons through hypothesis generation, experiment design, and result interpretation systematically |
| **Ethical Debate Framework (EDF)** | Ethical Reasoning + Debate & Critique + Multi-Agent | AI ethics, moral philosophy | Multiple agents embody different ethical frameworks, debating to find morally robust solutions |
| **Risk-Aware Planning (RAP)** | Financial Risk Reasoning + Planning + Counterfactual | Portfolio management, stress testing | Plans investments while simulating counterfactual market scenarios to assess risk exposure |
| **Narrative CoT with Memory (NCM)** | Narrative/Story Reasoning + Chain-of-Thought + Memory | Creative writing, interactive fiction | Generates stories with coherent plot chains while maintaining character and plot consistency in memory |
| **Mathematical Proof Networks (MPN)** | Mathematical Reasoning + Graph-of-Thought + Neural Theorem Proving | Formal mathematics, proof assistants | Represents proofs as graphs where nodes are lemmas, with neural guidance for proof search |
| **Visual Tool Composition (VTC)** | Visual Reasoning + Tool Use + Composition | Multimodal agents, GUI automation | Composes visual perception tools (detection, OCR) with reasoning to interact with visual interfaces |
| **Code Reflection Trees (CRT)** | Code Reasoning + Tree-of-Thought + Reflection | Program synthesis, bug fixing | Explores multiple code solutions as a tree, reflecting on compilation and execution results |
| **Physical Simulation CoT (PSCoT)** | Common-sense Physics + Chain-of-Thought + Mental Simulation | Robotics, embodied AI | Simulates physical interactions mentally while reasoning about action sequences and their outcomes |
