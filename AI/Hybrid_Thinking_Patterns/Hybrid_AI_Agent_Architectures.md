## Section 2: Hybrid AI Agent Architectures (Planning + Execution)

| Hybrid Thinking Pattern | Combined Patterns | Where It Is Used | Description |
|-------------------------|-------------------|------------------|-------------|
| **Reflective ReAct (R-ReAct)** | ReAct + Reflection | Autonomous web agents, coding assistants | Interleaves reasoning and action while continuously reflecting on action outcomes to adjust strategy mid-execution |
| **Planned Tool Composition (PTC)** | Planning + Tool Use | Complex API orchestration, data pipeline automation | Creates long-term plans that dynamically compose multiple tools, with replanning when tool outputs deviate from expectations |
| **Hierarchical Tool Planning (HTP)** | Hierarchical Agent Pattern + Tool Use | Enterprise automation, DevOps AI | Manager agent creates high-level plans that decompose into sub-plans, each selecting appropriate tools for specialized subtasks |
| **Multi-Agent Tool Debate (MATD)** | Multi-Agent Orchestration + Tool Use + Debate | Scientific research teams, due diligence AI | Multiple agents use different tools to gather evidence, then debate findings to reach robust conclusions |
| **Self-Improving Plan Execute (SIPE)** | Plan-and-Execute + Reflection | Robotics, autonomous vehicles | Executes plans while reflecting on execution quality, using feedback to improve future planning strategies |
| **Concurrent Reflective Agents (CRA)** | Concurrent/Fan-out Pattern + Reflection | High-reliability systems, medical diagnosis | Multiple agents process tasks in parallel, each reflecting on their own outputs, with cross-agent consistency checking |
| **Adaptive ReWOO (A-ReWOO)** | ReWOO + Dynamic Planning | Cost-optimized cloud agents, resource-constrained systems | Anticipates evidence needs but dynamically adjusts plan when evidence retrieval reveals unexpected information |
| **Human-on-the-Loop Reflection (HOTLR)** | Human-in-the-Loop + Reflection | Clinical decision support, legal review | Agent reflects on when human input is most valuable, strategically escalating for reflection rather than just decisions |
| **Agentic RAG with Planning (ARAG-P)** | Agentic RAG + Planning | Deep research systems, investigative AI | Plans information gathering strategy, executes targeted retrievals, synthesizes findings, and replans based on gaps |
| **Tool-Use with Verification (TUV)** | Tool Use + Chain of Verification | Financial auditing, compliance checking | Uses tools to gather data, then independently verifies tool outputs through additional queries before finalizing answers |
| **Recursive Subgoal Planning (RSP)** | Subgoal Decomposition + Recursive Agent Networks | Project management AI, complex engineering | Breaks goals into subgoals that can spawn their own planning agents, creating adaptive hierarchical execution |
| **State-Based Tool Selection (SBTS)** | State Machine Agents + Tool Use | Interactive customer service, workflow automation | Transitions between states based on tool outputs, with each state having specific tool preferences and reasoning patterns |
| **Event-Driven RePlanning (EDRP)** | Event-Driven Agents + Dynamic Planning | Real-time trading, crisis management | Continuously monitors events, triggering rapid replanning when significant environmental changes occur |
| **Memory-Augmented Tool Use (MATU)** | Tool Use + Memory-Augmented Reasoning | Personal assistants, long-term task management | Remembers successful tool combinations and failures, using episodic memory to guide future tool selection |
| **Peer-to-Peer Tool Sharing (PPTS)** | Peer-to-Peer Collaboration + Tool Use | Distributed scientific computing, open research | Agents share tools and results directly, with emergent tool-use patterns arising from collaborative problem solving |
