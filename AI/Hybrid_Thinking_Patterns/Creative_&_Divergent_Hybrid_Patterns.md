## Section 10: Creative & Divergent Hybrid Patterns

| Hybrid Thinking Pattern | Combined Patterns | Where It Is Used | Description |
|-------------------------|-------------------|------------------|-------------|
| **Evolutionary Conceptual Blending (ECB)** | Genetic Algorithms + Conceptual Blending | Design generation, creative writing, architecture | Iteratively mutates and combines different concepts, selecting the most "novel" and "useful" blends through a fitness function over time. |
| **Generative Lateral Search (GLS)** | Generative AI + Lateral Thinking | Scientific discovery, brainstorm assistants | Uses LLMs to generate widely divergent ideas and a constrained search algorithm to map these "crazy" concepts back to practical solutions. |
| **Multi-Perspective SCAMPER Agents (MPSA)** | Multi-Agent Orchestration + SCAMPER | Product design, marketing strategy | Different specialized agents apply different parts of the SCAMPER framework (Substitute, Combine, Modify, etc.) in parallel to an idea, then synthesize. |
| **Counterfactual Ideation Engine (CIE)** | Counterfactual Reasoning + Divergent Thinking | Storytelling, strategic forecasting | Generates scenarios by altering historical or logical constraints (e.g., "What if gravity worked differently?") and reasoning through the consequences. |
| **Stochastic Analogy Mapping (SAM)** | Random Stimulation + Analogical Reasoning | Overcoming creative blocks, innovation consulting | Injects random noise or distinct database entries into the prompt context, forcing the reasoning engine to map analogies back to the core problem. |
